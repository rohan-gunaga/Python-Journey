# Student Management System

A console-based Student Management System built with Python.

## 🚀 Features

- Add students
- View all students
- Search students by name
- Calculate student grades
- Save student data using JSON
- Load saved data when the program starts
- Handle invalid input using exception handling

## 🛠️ Concepts Used

- Python
- Object-Oriented Programming (Classes & Objects)
- Lists
- Loops & Conditions
- Functions
- Exception Handling
- JSON File Handling
- Git & GitHub

## 💾 Data Persistence

Student information is stored in `students.json`.

The program automatically saves student data when a new student is added and loads the saved data when the program starts.

## ▶️ How to Run

```bash
python student_management.py
